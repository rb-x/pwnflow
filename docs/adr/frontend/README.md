## Topics Covered

- **Framework & Language**: React (latest stable), TypeScript (latest stable)
- **Build Tool**: Vite (latest stable)
- **Styling**: Tailwind CSS (latest stable), shadcn/ui components
- **State Management**: Zustand (global), TanStack Query (server)
- **Forms**: React Hook Form, Zod validation
- **Rich Text**: TipTap editor
- **Visualization**: XYFlow for diagrams
- **HTTP Client**: Axios
- **Routing**: React Router (latest stable)
